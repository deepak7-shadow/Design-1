# RANN MAHAL — Luxury Heritage Desert Sanctuary

A bespoke cinematic scroll animation website crafted from the exact design and motion in `ff.mp4`.

## Features

- **Kinetic Scrubbed Canvas Engine**: 143 high-fidelity frames preloaded in WebP format, providing instant, 0-latency, 60–120 FPS scrubbing mapped to scroll position.
- **Cinematic Chapters**:
  - **Chapter I (The Palace)**: *"Where the desert keeps its gold."* — Thar Frontier, Rajasthan
  - **Chapter II (The Gate)**: *"Nine feet of teak, opened once a day."*
  - **Chapter III (The Water Court)**: *"A courtyard built to hold the evening."*
  - **Chapter IV (The Colonnade)**: *"Sixty columns. One view."*
  - **Chapter V (The Terrace)**: *"Stay until the sun clears the fields."* with detailed reservation details and contact options.
- **Right-Side Roman Numeral Navigation Rail**: Interactive roman numerals (`I`, `II`, `III`, `IV`, `V`) with a dynamic gold progress track and traditional *jharokha* arch indicator. Click any numeral to smoothly fly directly to that chapter.
- **Fixed Top Header**:
  - `THE PALACE`, `THE GATE`, `THE COURT` quick jumps
  - Brand identity with gold divider lines: `— R A N N  M A H A L —`
  - Interactive `RESERVE` button
  - Ambient Sound toggle (`AMBIENCE`) powered by Web Audio API generative sitar & desert breeze resonance.
- **Private Estate Hold Drawer**: Slide-out glassmorphic reservation system with date selection, sanctuary suite picker, and bespoke dining/safari requests.
- **Fluid Keyboard & Touch Controls**: Up/Down arrow keys, Page Up/Down, smooth touch scrolling, and custom gold aura cursor.

## Run Locally

Open `index.html` directly in any modern browser, or run a local server:

```bash
python -m http.server 3000
```

Then visit: [http://localhost:3000](http://localhost:3000)
